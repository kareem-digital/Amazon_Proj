## 📊 1. Executive Summary & Specification Overview

This document provides a comprehensive, formal specification and change audit for the **VOW Advertising Platform Strategy Module (v2.0)**. It synthesizes **28 architectural change requirements** identified during the technical review of the v1.1.0 legacy specification into an enterprise-ready, production-grade schema and state-machine design.

### Key Architectural Shifts (v2.0)
- **CTV-First Agentic Flow (v5)**: Prioritizes upper-funnel Connected TV (CTV) and Prime Video inventory, streamlining user input prompts down from 15+ manual questions to **3 simple core questions** (Flight Dates, Target Market, Total Budget).
- **Automated Parameter Inference**: Strategy Naming, Primary Currency, Product Categories, Base Bids, and Ad Formats are automatically inferred or auto-generated by the Planning Agent.
- **CPM Pricing Abstraction**: Eliminates technical deal tables; surfaces rate-card Effective CPMs to the user while performing deal matching in the background.
- **Unified Baseline Targeting**: Automatically applies country geo-targeting and living room CTV device defaults upon inventory selection.
- **Flexible Downstream Modular Execution**: Decouples tracking setup (ASINs, conversion pixels) and creative binding, allowing post-creation field updates via `PATCH /api/strategies/{id}/`.

## 🎯 3. Technical Changes Categorized by System Subsystem

### Subsystem A: Campaign Identity & Brief Inferences
1. **Auto-Generated Strategy Naming**: The Planning Agent auto-generates structured strategy names (`{Category}_{Market}_{Goal}_{MonthYear}`) and auto-repairs duplicate names by appending version suffixes (`_v2`). *(Item 7)*
2. **Automated Primary Currency Inference**: Primary currency is automatically derived from target market ISO code (`GB` $\rightarrow$ `GBP` £, `DE` $\rightarrow$ `EUR` €, `US` $\rightarrow$ `USD` $). User prompt is eliminated. *(Item 9)*
3. **Automated Channel Format (`streaming_tv`)**: Channel format for DSP CTV strategies is defaulted to `streaming_tv`. Format selection prompt is eliminated. *(Item 14)*
4. **Product Category Brief Inference**: Product Category is inferred directly from brief text context or inherited from advertiser default category profile. Dropdown selection prompt is eliminated. *(Item 15)*

---

### Subsystem B: Budgeting, Bidding & Pricing Models
1. **Simplified Single-Market Budget Input**: Budget for single-market campaigns is entered as a simple numeric input (`Total Budget: £10,000.00`) instead of populating a multi-row table UI widget. *(Item 11)*
2. **Base Bid Omission for CTV**: Base CPM bid prompt is omitted for CTV strategies. Campaign pricing is defined by selected deal CPM rate cards. *(Item 12)*
3. **Frequency Target Numeric Value (1–5)**: When KPI target type is `frequency`, an explicit numeric target value between `1` and `5` impressions per user can be specified (Defaults to `3`). *(Item 10)*
4. **Advertiser Profile Frequency Cap Inheritance**: Frequency capping rules are optional; if omitted, the Planning Agent automatically pulls and applies advertiser profile defaults (e.g. 3 impressions per 24 hours). *(Item 13)*

---

### Subsystem C: Inventory Selection & Programmatic Deals
1. **Automated Background Deal Selection**: Technical UI deal checkbox tables are eliminated. The agent automatically matches deals in the background based on brief parameters (`market`, `flight_dates`, `channel=streaming_tv`, `genre`). *(Item 18)*
2. **CPM Pricing Abstraction**: Technical deal IDs are hidden from the user interface; the platform surfaces ONLY the resulting Effective CPM rate card to the user. *(Item 18)*
3. **Amazon Native Audiences on 3P Inventory**: Advertisers CAN apply Amazon 1P native audiences (in-market, lifestyle, demographic) to 3P inventory deals (Netflix, Disney+, Hulu, Roku) when buying via Amazon DSP. Standard 1P VCPM data fee applies. *(Item 19)*
4. **3P Targeting Flexibility**: For 3P inventory (Netflix, Hulu, Disney+), targeting is NOT restricted to publisher-only. Advertisers can choose between **Amazon DSP Targeting** (device/geo) or **Publisher / SSP Supply-Side Targeting**. *(Item 1)*

---

### Subsystem D: Unified Targeting & Baseline Defaults
1. **Unified Baseline Targeting**: Once inventory is selected, **Default Baseline Targeting** (`Market Country Geo` + `CTV Living Room Devices`) is automatically applied. *(Item 5)*
2. **Location Geo-Targeting Market Default**: Location geo-targeting automatically defaults to the full target market country (e.g. `GB` $\rightarrow$ United Kingdom). Postcode lists are optional for hyper-local refinement. *(Item 21)*
3. **Device Type Advertiser Inheritance**: Device type targeting automatically inherits advertiser profile level preferences (e.g. `CTV only` / Living Room Devices). *(Item 22)*
4. **Audience Suggestion API Response Shape**: The suggest API endpoint `POST /api/audience-sets/suggest/` returns a **flat list of recommended audience sets** (`List[AudienceSet]`). Nested bundle keys (`bundles.narrow/balanced/broad`) are NOT supported by backend API. *(Item 20)*
5. **Audience Profile Naming ("Wide")**: Audience profile "Broad" is renamed to **"Wide"** per client vocabulary. Single 1P data fee applies per data provider (no compounding within same provider). *(Item 2)*

---

### Subsystem E: Downstream Execution, Creatives & Tracking Setup
1. **Click-Through URL Optionality for CTV**: Click-through URL is **Optional** for `streaming_tv` living room ad placements (Required only for Display/OLV). *(Item 25)*
2. **Dynamic Channel-Level Creative Approval Status**: Replaced hardcoded publisher status fields with a dynamic per-channel approval dictionary: `channel_approval_statuses: Dict[str, ApprovalStatusEnum]` (`"amazon"`, `"netflix"`, `"disney_plus"`, `"paramount_plus"`, `"channel_4"`, `"roku"`). *(Item 26)*
3. **Flexible Non-Sequential Downstream Execution**: Post-finalization downstream setup modules (**Tracking Setup**: ASINs / pixels vs **Creatives Binding**: video files / URLs) are decoupled and non-sequential; either can occur first based on asset readiness. *(Item 27)*
4. **Post-Creation Strategy Field Updates**: `product_location`, `product_asins`, and tracking parameters do NOT block initial strategy creation. They can be updated on the strategy entity post-creation via `PATCH /api/strategies/{id}/`. *(Items 16, 17, 28)*

---

### Subsystem F: REST API Catalog & Plan Approval Workflow
1. **Simplified Plan Approval & Direct Status Transition**: Plan approval is simplified to a single status update (`draft` $\rightarrow$ `finalised` / `active`); manager approval routing workflows are omitted. *(Item 23)*
2. **Simplified Strategy Creation Endpoint (`POST /api/simple-strategies/`)**: Strategy creation for CTV simplified campaigns uses the dedicated `POST /api/simple-strategies/` REST endpoint, accepting a streamlined Pydantic payload. *(Item 24)*
3. **Partial Update Endpoint (`PATCH /api/strategies/{id}/`)**: Supported for updating deferred ASINs, selling location, and tracking parameters on existing strategy entities post-creation. *(Item 28)*

## 💻 4. Production-Grade Strategy Pydantic Data Model (v2.0)

```python
"""
VOW Platform - Strategy Module Pydantic Data Models (v2.0)
Production-grade Python schemas reflecting all v2.0 architectural updates.
"""

from enum import Enum
from typing import List, Optional, Dict, Any
from pydantic import BaseModel, Field, HttpUrl

# ==========================================
# ENUM DEFINITIONS (v2.0)
# ==========================================

class InventoryTierEnum(str, Enum):
    AMAZON_OWNED = "AMAZON_OWNED"
    THREE_P_PRE_CURATED = "THREE_P_PRE_CURATED"
    THREE_P_NEEDS_CURATION = "THREE_P_NEEDS_CURATION"

class TargetingLocationEnum(str, Enum):
    AMAZON_DSP = "AMAZON_DSP"
    SUPPLY_SIDE_SSP = "SUPPLY_SIDE_SSP"

class ChannelTypeEnum(str, Enum):
    DSP = "dsp"
    SPONSORED = "sponsored"

class GoalEnum(str, Enum):
    AWARENESS = "AWARENESS"
    CONSIDERATION = "CONSIDERATION"
    CONVERSION = "CONVERSION"

class KPIEnum(str, Enum):
    REACH = "reach"
    FREQUENCY = "frequency"
    CTR = "ctr"
    CPC = "cpc"
    CPA = "cpa"
    CPDPV = "cpdpv"

class ProductLocationEnum(str, Enum):
    ON_AMAZON = "ON_AMAZON"
    NOT_SOLD_ON_AMAZON = "NOT_SOLD_ON_AMAZON"

class FormatEnum(str, Enum):
    DISPLAY = "display"
    ONLINE_VIDEO = "online_video"
    STREAMING_TV = "streaming_tv"
    PRIME_VIDEO = "prime_video"

class CurrencyEnum(str, Enum):
    EUR = "EUR"
    GBP = "GBP"
    USD = "USD"

class StrategyStatusEnum(str, Enum):
    DRAFT = "draft"
    FINALISED = "finalised"
    ACTIVE = "active"
    PAUSED = "paused"

class ApprovalStatusEnum(str, Enum):
    APPROVED = "APPROVED"
    PENDING = "PENDING"
    REJECTED = "REJECTED"
    NOT_SUBMITTED = "NOT_SUBMITTED"

# ==========================================
# STEP-BY-STEP SLOT SCHEMAS (v2.0)
# ==========================================

class DateRangeSchema(BaseModel):
    lower: str = Field(..., description="ISO Date String YYYY-MM-DD")
    upper: str = Field(..., description="ISO Date String YYYY-MM-DD")
    bounds: str = Field("[)", description="Interval boundary notation")

class Step1DetailsSlotSchema(BaseModel):
    """Step 1: Strategy Details (Inferred Naming, Currency, Categories & Formats)"""
    name: Optional[str] = Field(None, description="Auto-generated if omitted e.g. Education_UK_Awareness_Aug2026")
    flight_dates: DateRangeSchema = Field(..., description="Campaign Flight Date Range")
    markets: List[str] = Field(..., description="ISO 2-letter Country Codes e.g. ['GB']")
    primary_currency: Optional[CurrencyEnum] = Field(None, description="Inferred automatically from market ISO e.g. GB -> GBP")
    formats: List[FormatEnum] = Field(default=[FormatEnum.STREAMING_TV], description="Selected Ad Formats (Defaults to streaming_tv)")
    product_categories: List[int] = Field(default_factory=list, description="Inferred from brief text or advertiser default profile")
    product_location: Optional[ProductLocationEnum] = Field(None, description="Optional upfront; updated post-creation via PATCH")
    product_asins: List[str] = Field(default_factory=list, description="Deferred downstream - updated post-creation via PATCH")

class MarketBudgetBidSchema(BaseModel):
    market: str = Field(..., description="ISO 2-letter Country Code")
    budget: str = Field(..., description="Total Budget Decimal String (Single numeric input for single market)")
    base_bid: Optional[str] = Field(None, description="Base CPM Bid (Omitted in CTV, derived from deal CPM)")

class Step2GoalKPIBidSlotSchema(BaseModel):
    """Step 2: Goal, KPI & Bid (Single Market Budget & Frequency Target Range)"""
    goal: GoalEnum = Field(GoalEnum.AWARENESS, description="Primary Strategy Goal (Defaults to AWARENESS for CTV)")
    kpi_target_type: KPIEnum = Field(KPIEnum.REACH, description="Primary Metric Target (reach | frequency)")
    kpi_target_value: Optional[int] = Field(default=3, ge=1, le=5, description="Frequency target value (1 to 5 range)")
    frequency_cap: Optional[Dict[str, Any]] = Field(None, description="Inherits advertiser profile default capping if omitted")
    ad_tag_conversions: List[str] = Field(default_factory=list, description="Tracked Ad Tag Conversions (Updated post-creation)")
    market_budgets: List[MarketBudgetBidSchema] = Field(..., description="Budget Allocations")

class SelectedDealSchema(BaseModel):
    """Step 3: Selected Inventory Deal (Auto-matched by Agent; CPM Pricing Surfaced)"""
    deal_id: str = Field(..., description="Deal ID e.g. EXT7P75718S8MNR (Auto-matched by agent)")
    name: str = Field(..., description="Deal Name")
    cpm: str = Field(..., description="Fixed or Floor CPM Rate Card Price (Surfaced to user)")
    inventory_tier: InventoryTierEnum = Field(..., description="AMAZON_OWNED | THREE_P_PRE_CURATED | THREE_P_NEEDS_CURATION")
    targeting_choice: TargetingLocationEnum = Field(TargetingLocationEnum.AMAZON_DSP, description="AMAZON_DSP | SUPPLY_SIDE_SSP")
    allocated_budget_percentage: Optional[float] = Field(None, description="Percentage of budget allocated to deal")

class Step3DealsSlotSchema(BaseModel):
    selected_deals: List[SelectedDealSchema] = Field(..., description="Auto-matched Inventory Deals with CPM pricing")

class SelectedAudienceSetSchema(BaseModel):
    audience_set_id: str = Field(..., description="Audience Set UUID")
    name: str = Field(..., description="Audience Set Name")
    vcpm_fee: str = Field(..., description="VCPM Fee Decimal")

class UnifiedTargetingSlotSchema(BaseModel):
    """Step 4: Unified Targeting (Default Baseline + Optional Refinements)"""
    locations: List[str] = Field(default_factory=list, description="Defaults to target market country ISO code if empty")
    device_types: List[str] = Field(default=["CTV"], description="Inherits advertiser profile preference (CTV Living Room)")
    postcodes: List[str] = Field(default_factory=list, description="Optional Postcodes / Zip codes for hyper-local targeting")
    matching_mode: str = Field("Exact", description="Similar | Exact")
    selected_audience_sets: List[SelectedAudienceSetSchema] = Field(default_factory=list, description="Optional audience sets (Returned as flat list from suggest API)")

class SelectedCreativeSchema(BaseModel):
    """Step 5: Selected Creative Asset & Per-Channel Approval Status"""
    asset_id: str = Field(..., description="Media Asset UUID")
    asset_name: str = Field(..., description="Media Asset File Name")
    click_through_url: Optional[HttpUrl] = Field(None, description="Optional landing page URL for streaming_tv (Required for Display/OLV)")
    channel_approval_statuses: Dict[str, ApprovalStatusEnum] = Field(
        default_factory=dict, 
        description="Dynamic read-only approval status map per inventory channel e.g. {'amazon': 'APPROVED', 'paramount_plus': 'PENDING'}"
    )

class Step5CreativeSlotSchema(BaseModel):
    selected_creatives: List[SelectedCreativeSchema] = Field(..., description="Selected Media Assets with per-channel approvals")

# ==========================================
# COMPREHENSIVE FULL STRATEGY SCHEMA (v2.0)
# ==========================================

class FullStrategySchema(BaseModel):
    """Full Strategy Object Model (v2.0)"""
    id: Optional[str] = Field(None, description="System Assigned Strategy ID e.g. VMA2026365")
    advertiser_id: str = Field(..., description="Parent Advertiser UUID")
    channel_type: ChannelTypeEnum = ChannelTypeEnum.DSP
    details: Step1DetailsSlotSchema
    goal_kpi_bid: Step2GoalKPIBidSlotSchema
    deals: Step3DealsSlotSchema
    targeting: UnifiedTargetingSlotSchema
    creatives: Step5CreativeSlotSchema
    status: StrategyStatusEnum = Field(StrategyStatusEnum.FINALISED, description="Direct status update: draft -> finalised -> active")
    is_syncing: bool = Field(False, description="Background DSP sync status")
```
